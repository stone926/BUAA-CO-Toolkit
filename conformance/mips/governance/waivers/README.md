# One-case waivers

Waivers are a last resort for a single non-ruleable intentional divergence.
Each `WAIVER-*.json` binds exact case/engine/raw/expected/actual/mismatch hashes,
a checked-in minimal reproduction and exact event/field scope. Wildcards and
expired or stale-match records fail validation. Formal use additionally
requires the exact candidate's append-only approval envelope.

No waiver is active in phase 0.
